# الكذّاب

لعبة جماعية: الشاشة تعرض سؤال غريب، كل واحد يكتب كذبة من جواله، وبعدين الكل يحاول يكشف الإجابة الصحيحة من بين الكذبات.

## التشغيل في البيت (نفس الواي فاي)

1. ثبّت Node.js (نسخة 18 أو أحدث)
2. افتح الطرفية داخل المجلد وشغّل:

```
npm install
npm start
```

3. افتح صفحة الشاشة على اللابتوب أو التلفزيون:

```
http://localhost:3000/host
```

4. الأهل يمسحون الباركود من جوالاتهم (لازم يكونون على نفس الواي فاي)

## الرفع على Render (يشتغل من أي مكان)

1. ارفع المجلد على مستودع في GitHub (بدون مجلد node_modules)
2. في Render اختر: New ثم Web Service، واربطه بالمستودع
3. الإعدادات:
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: Free
4. افتح رابط الموقع وأضف في آخره `/host` للشاشة

ملاحظة: الخطة المجانية تنام بعد فترة بدون استخدام، فأول فتح ياخذ تقريبًا دقيقة.

## تعديل اللعبة

- الأسئلة في ملف `questions.js`
- الوقت والنقاط في أول ملف `server.js`
